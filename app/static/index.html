▸ 怎么获取 token？（点开看教程）
1. 电脑 Chrome 打开 联通看家网页版 并登录；
2. 按 F12 → Network（网络）→ 点对应摄像头的直播预览；
3. 找到地址为 wss://…/h5player/live 的连接，点 Payload/消息：
　· token：请求参数 JSON 里的 token 字段；
　· deviceId：同在参数 JSON 里（形如 xxxxS_xxxx）；
　· wsHost：wss:// 后面的主机:端口；
　· relayServer：中继参数（如有）。
token 有效期有限，过期后重新抓一次即可。联通未开放账号密码直连接口，App 内部票据流程无法在服务器上完成，所以采用 token 直填。
